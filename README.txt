YE BOT KIA KARTA HAI?
---------------------
1. JAB KOI "STATUS" MENTION KARE → Message AUTO DELETE
2. JAB KOI BLOOD REQUEST KARE → Auto reply with form link
3. Naya member join kare → Welcome message

QR CODE KA NEW TARIKA:
----------------------
Ab QR Code terminal mein garbled/black blocks ki shakal mein NAHI aayega!

Instead, ye ek CLICKABLE LINK aayega jaise:
https://api.qrserver.com/v1/create-qr-code/?size=400x400&data=....

Is link par click karein → Browser mein QR Code image khulegi → Scan karein!

FILES:
------
• bot.js      → Main bot code
• config.js   → Keywords aur messages edit karne ke liye
• package.json→ Dependencies

RENDER.COM PAR SETUP:
---------------------
Step 1: Purani repo se SARI files delete karke ye nayi files upload karein
Step 2: "New Web Service" ya "Manual Deploy" karein
Step 3: Build Command: npm install
Step 4: Start Command: node bot.js
Step 5: Deploy!

QR CODE SCAN KARNE KA TARIKA:
------------------------------
1. Logs mein ye line dhoondhein:
   "📱 Is link ko click karein..."

2. Uske neeche ek link hogi jaise:
   https://api.qrserver.com/v1/create-qr-code/?size=400x400&data=....

3. US LINK PAR CLICK KAREIN!
   (Ya link copy karke Chrome mein paste karein)

4. Browser mein QR Code image khulegi

5. Apne BOT NUMBER ke WhatsApp se scan karein:
   WhatsApp → 3 Dots → Linked Devices → Link a Device

IMPORTANT:
----------
• Bot number ko HAR group mein ADMIN banana ZAROORI hai
• Status delete karne ke liye admin hona MUST hai
• Ek ALAG number use karein (apna personal number nahi)
• QR Code har 20 second mein refresh hota hai, jaldi scan karein!

CUSTOMIZE:
