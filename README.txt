PAKISTAN WELFARE SOCIETY - WHATSAPP BOT
BAILEYS VERSION (NO CHROME NEEDED!)
=============================================

YE BOT KIA KARTA HAI?
---------------------
1. JAB KOI "STATUS" MENTION KARE → Message AUTO DELETE
2. JAB KOI BLOOD REQUEST KARE → Auto reply with form link
3. Naya member join kare → Welcome message

YE VERSION KIA ALHAI?
---------------------
✅ Chrome/Puppeteer NAHI chahiye
✅ Render par ASANI se chalega
✅ Build time KAM (2-3 min)
✅ Memory KAM use karega

FILES:
------
• bot.js      → Main bot code
• config.js   → Keywords aur messages edit karne ke liye
• package.json→ Dependencies

RENDER.COM PAR SETUP:
---------------------
Step 1: Render.com par free account banayein
Step 2: "New Web Service" click karein
Step 3: GitHub se connect karein ya "Upload" karein
Step 4: Build Command: npm install
Step 5: Start Command: node bot.js
Step 6: Deploy!

QR CODE SCAN:
-------------
Build ke baad Logs mein QR Code ayega.
Apne BOT NUMBER se scan karein.

IMPORTANT:
----------
• Bot number ko HAR group mein ADMIN banana ZAROORI hai
• Status delete karne ke liye admin hona MUST hai
• Ek ALAG number use karein (apna personal number nahi)
• Session save ho jayegi, dobara QR nahi ayega (mostly)

CUSTOMIZE:
----------
config.js file mein ja kar:
• Apna form link change karein
• Keywords add/remove karein
• Messages change karein
